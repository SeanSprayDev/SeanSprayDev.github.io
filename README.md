Sean Spray Portfolio



A responsive personal portfolio built with HTML, CSS, and JavaScript to present my software engineering projects, technical interests, and project documentation.



The design direction is a dark, moonlit archive/codex style with custom visual details, responsive layout behavior, and an interactive project carousel.



Purpose



This portfolio was built to serve as a central place for my software engineering work, including tools, systems, interactive projects, and project case studies.



The goal was to create something more personal than a basic template while still keeping the site readable, 

professional, and easy to navigate.
